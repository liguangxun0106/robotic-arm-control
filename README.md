# 机械臂力-位置混合控制仿真验证

## 📋 项目概述

本项目实现了基于MATLAB/Simulink的机械臂**力-位置混合控制**系统的仿真验证。通过将位置控制和力控制进行混合，实现机械臂在与环境交互过程中既能准确跟踪期望轨迹，又能精确控制接触力。

### 系统框图
```
【位置控制路径】
期望位置 x_d → Δx → ∫S → f⁻¹ → 位置控制输出 u_p
                              ↓
                            合并(+)
                              ↓
【力控制路径】          机器人动力学 → 位置x → ⊕ → 环境
期望力 F_d → ΔF → ∫S → ∫S → 力矩控制 u_f → +    反馈F_e
                    ↑____________环境力反馈____________↑
```

## 🔧 参数调优建议

### 位置控制器调优
```matlab
% 若位置超调过大：
Kp = Kp * 0.8;    % 减小比例增益
Kd = Kd * 1.2;    % 增加微分增益

% 若响应太慢：
Kp = Kp * 1.2;    % 增加比例增益
Ki = Ki * 1.1;    % 增加积分增益

% 若出现振荡：
Kd = Kd * 1.5;    % 增加微分增益
Ki = Ki * 0.9;    % 减小积分增益
```

### 力控制器调优
```matlab
% 关键原则：力控制增益应远小于位置控制增益
% 建议：Kp_force ≈ Kp_pos / 100

% 若力控制不稳定：
Kp_force = Kp_force * 0.5;
Kd_force = Kd_force * 1.5;

% 若力响应太慢：
Kp_force = Kp_force * 1.5;
Ki_force = Ki_force * 1.2;
```

### 混合权重调整
```matlab
% 权重必须满足：w_pos + w_force = 1.0

% 位置优先：
w_pos = 0.8; w_force = 0.2;

% 力优先：
w_pos = 0.5; w_force = 0.5;

% 动态切换（根据接触状态）：
if contact_force < 0.5
    w_pos = 1.0;    % 未接触，纯位置控制
    w_force = 0.0;
else
    w_pos = 0.7;    % 已接触，混合控制
    w_force = 0.3;
end
```

## 🔗 核心概念

### 混合力-位置控制原理

在与刚性环境接触的机械臂控制中，传统的纯位置控制可能导致过大的接触力，而纯力控制则无法保证轨迹精度。混合控制的思想是将任务空间分解为：

- **位置受约束方向** (Position Constrained): 使用位置控制
- **力受约束方向** (Force Constrained): 使用力控制

**综合控制律**：
```
τ = w_pos · τ_pos + w_force · τ_force

其中：
τ_pos - 位置控制生成的力矩
τ_force - 力控制生成的力矩
w_pos, w_force - 权重系数，满足 w_pos + w_force = 1
```

### 优势
- ✓ 防止过大的接触力
- ✓ 保证轨迹跟踪精度
- ✓ 提高系统鲁棒性
- ✓ 应用于装配、磨削等任务

## 🐛 常见问题与解决

### Q1: 仿真不收敛？
**A**: 检查以下项：
- Kp是否过大
- 采样时间是否过长（应 ≤ 0.001s）
- 环境刚度是否过高

### Q2: 位置和力控制冲突？
**A**: 调整混合权重
- 增加w_pos如果位置误差大
- 增加w_force如果力误差大
- 避免两者都过大

### Q3: 如何处理接触时刻的冲击？
**A**: 
- 增加力控制的积分时间常数
- 使用软启动（渐进增加F_d）
- 调整环境阻尼参数

### Q4: 如何验证模型正确性？
**A**:
- 单独测试位置控制（w_force=0）
- 单独测试力控制（w_pos=0）
- 对比理论值和仿真值
